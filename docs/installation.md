# Installation

## Stable release

To install job-applicator, run this command in your terminal:

```sh
uv add job-applicator
```

Or if you prefer to use `pip`:

```sh
pip install job-applicator
```

## From source

The source files for job-applicator can be downloaded from the [Github repo](https://github.com/boplk/job-applicator).

You can either clone the public repository:

```sh
git clone https://github.com/boplk/job-applicator
```

Or download the [tarball](https://github.com/boplk/job-applicator/tarball/main):

```sh
curl -OJL https://github.com/boplk/job-applicator/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd job-applicator
uv sync
```
